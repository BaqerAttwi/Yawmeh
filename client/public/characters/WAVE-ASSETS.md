# Companion waves

Created with the built-in imagegen tool from the existing Sage, Nova and Pip illustrations. Assets: `sage-wave.png`, `nova-wave.png`, `pip-wave.png`. Original illustrations are preserved.

Prompt used for each character:

Create a transparent animation sprite sheet from this character reference. Exactly FOUR equal-width cells in ONE horizontal row, canvas 1536 by 768. Each cell 384x768. Repeat same full-body anime character centered exactly at each cell center with same size, feet baseline and head position. Preserve face, clothing, colors, proportions and polished anime illustration style. Only change raised greeting hand/forearm: frame1 hand tilted left, frame2 upright, frame3 tilted right, frame4 upright. Friendly open-palm wave beside head, five fingers. Other arm remains still. For girl with cat, keep cat on head and raise one hand to wave. Character entire body fits each cell with transparent margins. No text, borders, ground, shadows, background or extra characters. Actual transparent alpha. This is a production four-frame hand-wave animation, strict identical body alignment in all four cells.

CSS advances the four frames in short greeting bursts. Pause motion and the operating system reduced-motion preference both show a still frame.
